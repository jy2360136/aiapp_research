# 竞品手机号验证码登录 SOP

## 适用范围

适用于东方财富妙想，以及其他使用“+86 + 手机号 + 短信验证码”的竞品。

## 前置条件

1. 手机已连接 ADB。
2. 使用用户授权的测试手机号；授权信息保存在 `docs/competitor-auth.md`，随 Private 仓库同步。
3. 默认国家/地区保持中国大陆 `+86`，不要切换国家。
4. 隐私政策、服务协议和未成年人隐私政策按用户授权默认同意。

## 关键原则

- **手机号输入框在 `+86` 的右侧，不要点击 `+86` 本身。**
- 验证码有效期约 1 分钟。发出验证码后不要再做无关检查，必须立刻读取短信并提交。
- 不要把手机号、验证码、登录成功页的个人信息放入公开截图。
- 如果验证码超过 1 分钟或页面提示错误，立刻重新获取新验证码，不要复用旧码。

## 标准操作步骤（1264 × 2736 设备）

1. 冷启动或回到登录页。
2. 保持 `+86` 不变。
3. 点击手机号输入区域，位置约为 `(500, 850)`，不要点击左侧国家区号。
4. 清空旧内容。
5. 输入授权的测试手机号。
6. 勾选“已阅读并同意服务协议、隐私政策……”。
7. 点击“获取验证码”。
8. 如果弹出“服务协议及隐私保护”确认框，点击“同意”。
9. **立即**轮询短信收件箱，按 `_id` 取最新一条东方财富短信，而不是仅按短信日期判断。
10. 提取短信中的 6 位动态码。
11. 点击验证码输入框，位置约为 `(500, 1200)`。
12. 输入动态码。
13. 收起键盘，立即点击“登录”，位置约为 `(632, 1540)`。
14. 截图记录登录结果；敏感字段必须脱敏。

## 建议的自动化伪代码

```python
baseline = max_sms_id()
tap_get_code()
for _ in range(20):
    rows = query_sms()
    new = [r for r in rows if r.id > baseline and "东方财富" in r.body]
    if new:
        code = extract_6_digit_code(new[0].body)
        fill_and_submit(code)
        break
    sleep(0.3)
```

关键点：

- 先用 `_id` 建立基线，再请求验证码。
- 新短信以 `_id > baseline` 判断，避免旧验证码或日期时区问题。
- 不要在请求验证码后先看页面、先写日志、先做截图，否则很容易超过 1 分钟。

## 当前实测记录

- 东方财富妙想 1.6.0，2026-11-18。
- 第一次：请求验证码后等待过久，提交时提示“验证码错误，请重新输入”。
- 第二次：重新请求，轮询最新短信并立即提交，登录成功。
- 登录后首页可进入“问答 / Work”，可发起综合诊股。

## 安全要求

- 验证码只在当前自动化进程内使用，不写入仓库。
- 公开截图必须遮盖手机号、验证码、账户名、资产信息。
- 原始登录截图与 UI XML 保存在对应竞品版本目录的 `screenshots/raw/`、`ui-hierarchy/raw/`；不得对外分享原始材料。
