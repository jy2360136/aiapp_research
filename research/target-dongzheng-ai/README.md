## 不要先看什么

- `archive/20261117_flat_*`：上一轮未按版本和功能分区的平铺证据，只作历史归档。下一轮除非需要追溯旧结论，否则不要从这里开始。
- `.private/`：本机原始证据，可能包含账号、持仓、手机号或验证码，不入库。

## 版本规则

- 每个版本一个目录：`screenshots/v<版本号>_<日期>/`。
- 每个版本先看该目录下的 `README.md`。
- 功能截图只放在对应功能区：交易、盯盘、对话、自选、设置与协议。
- 文件名按 `stepNN_动作_结果.png` 命名，保证可以按操作顺序阅读。
- 新版本修复旧问题后，不要继续引用旧版本截图作为当前结论，只把它们作为回归对比。
