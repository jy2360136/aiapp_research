# 截图目录说明

截图按“版本 → 功能分区 → 操作步骤”组织。

```text
screenshots/
  v1.0.0_20261118/
    README.md
    01-盯盘/
    02-对话/
    03-自选/
    04-交易/
    05-设置与协议/
```

规则：

1. 先确定 App 版本号，再建立对应版本目录。
2. 每个版本目录必须有 README，写明本版本测试范围、结论和剩余问题。
3. 每张截图必须有目的，文件名包含步骤和验证目标。
4. 敏感页面只保存到 `.private/`，公开目录只放已脱敏截图。
5. 新版本不得把旧版本截图混入当前版本目录。
