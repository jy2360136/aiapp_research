# 01-盯盘

## 文件夹用途

记录冷启动、首页行情、市场模块、板块异动、热门榜单、个股详情和 F10 等“看市场”链路。

## 截图顺序

1. `step01`：冷启动 3 秒，行情仍为骨架/空值。
2. `step02`：冷启动 4.48 秒，主要行情出现。
3. `step03`：冷启动稳定态。
4. `step04`：首页稳定态。
5. `step05`：首页向下浏览市场模块。
6. `step06`：热门榜单。
7. `step07`：打开贵州茅台详情。
8. `step08`：日 K。
9. `step09`：资金页。
10. `step10`：简况 F10 长时间空白。

## 当前结论

- 首屏感知慢，主要问题不是 Activity 没启动，而是主要行情数据晚到。
- 个股 F10/看点存在长时间空白。
- 重路径内存峰值高，需要继续做 10 轮重复测试和 heap dump。

## 剩余问题

- 冷启动首内容时间。
- F10/看点空白。
- 高内存峰值和释放滞后。
