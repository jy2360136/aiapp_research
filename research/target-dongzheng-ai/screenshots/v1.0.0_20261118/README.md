## 本版本结论

1. AI 间歇性“服务开小差了”：历史复现 1 次；2026-11-18 连续 5 次冷启动首问均成功。
2. AI 正文未进入 UIAutomator/无障碍界面树：5 次复测均复现；TalkBack 需人工确认。
3. 冷启动约 2.0 秒返回 Activity，但主要行情约 3.7 秒出现、约 4.5 秒视觉稳定。
4. 重路径 PSS 峰值约 588 MB、4 个 WebView、976 个 View；暂不判定为持续泄漏。
5. 自选页“点击语义不一致”已撤回，后端证实是正常设计。
