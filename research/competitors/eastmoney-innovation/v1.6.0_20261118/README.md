# 东方财富妙想 v1.6.0

- 包名：`com.eastmoney.innovation.android`
- 版本：1.6.0
- 测试日期：2026-11-18
- 当前进度：已完成隐私授权、手机号验证码登录、登录后 AI 首页和一次“综合诊股”问答

## 当前结论

- 产品采用“问答 / Work”双模式，回答页提供“快速模型”选择。
- 首页推荐“综合诊股、基本面诊股、技术面诊股”，属于场景化任务入口。
- 本次综合诊股回答包含图表、更多数据模块和免责声明，偏重投研报告式呈现。
- 首次进入存在隐私政策和手机号登录两道门槛。

## 登录实测

- 手机号输入框必须输入有效手机号，不能输入股票代码。
- 验证码有效期约 1 分钟；第一次因等待过久失败，第二次请求后快速读取并提交成功。
- 具体流程见 `../../../../docs/competitor-login-sop.md`。
